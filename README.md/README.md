One original sentence a house cat would say in its own defence in the five seconds after sweeping a glass off the table, for make.fun's "Five Seconds to Explain the Glass" bounty ($2 USDC, top 8). Pure-stdlib Python entry. The program writes the line to `entry.txt`, deterministically, with no dependencies beyond vanilla Python.

> As the household's chief glass inspector, I can confirm it failed its drop test — the table is now certified free of unreliable glassware.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
